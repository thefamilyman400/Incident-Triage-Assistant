Deployment Steps

1
Create a Lightsail instance
  1. Go to console.aws.amazon.com/lightsail
  2. Click Create instance
  3. Choose: Linux/Unix → OS Only → Ubuntu 22.04 LTS
  4. Instance plan: $5/month (1 GB RAM — required for sentence-transformers)
  5. Give it a name e.g. triage-assistant
  6. Click Create instance and wait ~60 seconds
Do not pick the $3.50 plan — it only has 512 MB RAM. The sentence-transformers model needs ~600 MB to load.
2
Attach a static IP and open port 8080
  1. In Lightsail, go to Networking tab of your instance
  2. Click Attach static IP — create a new one (free while attached)
  3. In Firewall, click Add rule → Custom TCP · Port 8080 · Any IPv4

Note your static IP — this is the address your app will be accessible at.

3
Upload your project files

From your Windows machine, copy the project to the Lightsail instance. Replace YOUR_IP with the static IP you just assigned:

# From your local PowerShell (adjust path if needed)
scp -r "C:\Users\0025BL744\Desktop\watsonx" ubuntu@YOUR_IP:/opt/triage-assistant

# Or if using the Lightsail SSH key explicitly:
scp -i "C:\path\to\lightsail-key.pem" -r `
    "C:\Users\0025BL744\Desktop\watsonx\*" `
    ubuntu@YOUR_IP:/opt/triage-assistant
Tip: You can also use the Lightsail browser SSH console to git clone directly if your repo is on GitHub. Set REPO_URL before running deploy.sh.
4
Run the bootstrap script

SSH into the instance (use the browser SSH button in Lightsail, or your key):

ssh ubuntu@YOUR_IP

# On the instance:
cd /opt/triage-assistant
chmod +x deploy.sh
sudo ./deploy.sh

This installs Docker, sets up the systemd service, and configures the firewall. It takes ~2 minutes.

5
Set your API keys
sudo nano /opt/triage-assistant/.env

Fill in your values:

GOOGLE_API_KEY=AIzaSy...your_real_key...
GOOGLE_GEMINI_MODEL=gemini-2.0-flash
GROQ_API_KEY=gsk_...optional_backup...
GROQ_MODEL=llama-3.1-8b-instant
Security note: The .env file is chmod 600 (owner-read only) and is excluded from the Docker image by .dockerignore. It is only read at container startup via docker compose.
6
Start the application
cd /opt/triage-assistant
sudo docker compose up -d --build

First build takes 3–5 minutes (downloads Python base image + installs packages + bakes sentence-transformers model). Subsequent starts are under 30 seconds.

# Watch the startup logs
sudo docker compose logs -f

# Confirm it's healthy
curl http://localhost:8080/health
Once healthy, the app is live at: http://YOUR_LIGHTSAIL_IP:8080

Auto-restart on reboot

The deploy.sh script registers a systemd service. If the instance reboots (e.g. after an AWS maintenance event), the app starts automatically — no manual intervention needed.

Adding a custom domain (optional, free)

  1. Point your domain's A record to the Lightsail static IP
  2. Install Caddy on the instance as a reverse proxy with automatic HTTPS:
    sudo apt install -y caddy then configure /etc/caddy/Caddyfile with yourdomain.com { reverse_proxy localhost:8080 }
  3. Caddy auto-provisions a Let's Encrypt TLS certificate — HTTPS at no extra cost

Architecture on Lightsail

Internet ──► Lightsail Static IP :8080
                 │
                 ▼
         Docker container
         ┌─────────────────────────────┐
         │  uvicorn (1 worker)          │
         │  FastAPI app (main.py)       │
         │  sentence-transformers model │  ← baked into image
         │  315-chunk vector index      │  ← /app/app/vector_store (volume)
         └─────────────────────────────┘
                 │
                 ├─► Google Gemini API (LLM)
                 └─► Groq API (fallback LLM)
Vector store persistence: The Docker named volume vector_store survives container rebuilds and restarts. The expensive embedding step (30–60s on first run) only happens once.
